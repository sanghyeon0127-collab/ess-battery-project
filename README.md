# ESS 배터리 수명 예측

초기 100 사이클만으로 배터리 수명을 예측하고, 학습과 조건이 다른 배치에서도 통하는지 원논문(MAPE 9.1%)과 비교함.


## 프로젝트 개요
- 데이터셋 : MIT-Stanford Battery Dataset (Severson et al., Nature Energy 2019)
- 학습 데이터 : Batch 1 (2017-05-12)
- 평가 데이터 : Batch 2 (2018-02-20), 추가 평가 Batch 3 (2018-04-12)
- 태스크 : Regression — 초기 100 사이클로 Cycle Life(EOL = 0.88Ah 도달 사이클) 예측

## EDA

- Cycle Life 분포
	- 핵심 발견 : 배치마다 분포가 크게 다름 — 중앙값 B1 773 / B2 472 / B3 1,006, B2는 단수명(<500) 72%, B3는 장수명(>1,000) 52%.
	  최단수명 셀은 B1이 평균 C-rate 최대 정책 5.4C(80%)-5.4C(534·559), B3가 2단계(31→80% SOC) 전류 최대 정책 3.7C(31%)-5.9C(541).
	  라벨을 믿을 수 없는 셀 제외 — B1 10 · B3 2(EOL 도달 전 시험 종료), B2 8(VarCharge·SLOWCYCLE 비표준 프로토콜, 수명 라벨 없음)

- 열화 곡선 분석
	- 핵심 발견 : 초기 100 사이클 용량 변화는 중앙값 +0.18%로 거의 평탄 → 용량만으로는 장/단수명 구분 어려움.
	  수명의 약 70% 지점(knee)부터 열화가 급격히 가속되며, knee와 수명 상관 0.98 이상

- ΔQ(V) 곡선 분석
	- 핵심 발견 : 단수명 셀일수록 ΔQ 곡선이 크게 벌어지고(차이 최대 지점 약 2.9V),
	  log 분산이 세 배치 모두 수명과 강한 음의 상관(r -0.76 ~ -0.92) → 핵심 피처로 선택. B2·B3의 1사이클 정렬 차이(B1만 cycle 1이 저속 사이클)는 영향 미미

- 충전 속도(C-rate)와 수명의 관계
	- 핵심 발견 : 같은 정책 안에서도 수명이 최대 2.9배 차이 → 충전 조건만으로는 수명 설명 불가. 같은 정책 내에서 초기 용량이 클수록 길고(B1 r +0.73), 셀 온도가 높을수록 짧음(B1 r -0.38) → 셀 차이와 온도 차이가 함께 작용하는 것으로 추정

- 상관관계 / 다중공선성
	- 핵심 발견 : ΔQ 통계(var / min / mean)끼리 상관 0.98~0.996으로 사실상 같은 정보, VIF 최대 약 2.6만 → 피처를 늘려도 새 정보는 적고 계수만 불안정해짐

- 배치 간 차이
	- 핵심 발견 :
		- B2 수명 중앙값 472로 B1(773)의 약 60%, B2 셀 77%가 B1 최단 수명(534)보다 짧음
		- ΔQ만 세 배치 모두 수명과 같은 방향(r -0.76 ~ -0.92). 초기 용량·충전시간 등은 배치마다 분포와 관계 방향이 다름 (충전시간–수명 B1 +0.57 / B2 -0.94)
		- B2 안에 측정 충전시간이 10.04분(9셀, 수명 777~1,186) / 10.17분(30셀, 수명 392~514)으로 갈리는 두 그룹 존재. 같은 정책이 양쪽에 있어 정책이 아닌 시험 조건 차이로 추정 (원인은 데이터로 확정 불가)


## Modeling

### 데이터 처리
- 제외 셀 : B1 10 · B3 2(EOL 도달 전 시험 종료 → 라벨 ≠ 실제 수명), B2 8(비표준 프로토콜, 수명 라벨 없음) → 사용 B1 36 / B2 39 / B3 44
- 분할 : Batch 1 hold-out 20%를 **충전 정책 단위**로 분리, 나머지로 정책 단위 GroupKFold(5) CV
- 결측대체·스케일링은 Pipeline 안에서 학습 fold에만 fit, Test는 Batch 1 전체로 재학습한 모델로 1회 평가
- 모델·target 선택에는 CV·Valid만 사용 (Test 미사용)

### 피처 엔지니어링 전략
- 선택 피처 : `dQ_log_var` = log10(Var(ΔQ_100-10(V))) 1개
- Target : log10(cycle_life) — ΔQ와 log 수명이 직선 관계(EDA 3). CV·Valid 기준으로는 원래 값과 동률
- 근거 : B1에서 수명과 상관 1위(-0.84)이고, 세 배치 모두 같은 방향의 관계를 유지(-0.76 ~ -0.92, EDA 3) → dQ_log_var
  - 다른 피처는 배치마다 관계가 달라짐 (예 : 충전시간–수명 B1 +0.57 / B2 -0.94, EDA 4·6)
  - 트레이드오프 : 피처를 늘리면 조건이 다른 B2는 악화(1개 29.08% → 6개 41.50%), 조건이 비슷한 B3는 소폭 개선(12.61% → 11.32%) → 가장 다른 배치에서도 버티는 1개 선택
  - 주의 : EDA는 과제 요구에 따라 B1~3 전체로 수행 → 테스트 배치 정보가 피처 선택에 일부 반영됨

### 모델 선택 및 근거
- 후보 모델 : Ridge, ElasticNet, SVR, RandomForest, GradientBoosting
- 최종 모델 : Ridge (alpha=1.0)
- 선택 규칙 : 1-SE — CV 최저 모델의 CV MAPE + 1 표준오차 안에 드는 모델 중 가장 단순한 것
- 선택 이유 : 학습 셀 29개라 CV 차이가 표준오차 안이면 가장 단순한 모델 선택
  → CV 최저 SVR 8.60% + 1 표준오차(1.89) = 10.49% 이내 모델 중 가장 단순한 Ridge(8.86%). 피처 1개 직선 관계라 선형으로 충분

|---|---|---|
| Train (Batch 1 CV) | 8.86 | |
| Valid (Batch 1 Hold-out) | 8.84 | |
| Test (Batch 2) | 29.08 | |
| Gap (Train-Valid) | -0.03 | (+) : 과적합 의심 |
| Gap (Valid-Test) | 20.25 | (+) : 배치간 일반화 저하 의심 |
| Gap (Target-Test) | 19.98 | Target : 원논문 9.1% |
| Test (Batch 3) | 12.61 | |
| Gap (Batch2-Batch3) | -16.48 | Test 성능 간 비교 |
| Gap (Target-Test, Batch 3) | 3.51 | Batch 3 기준, 원논문 성능 비교 |

- 해석 :

  - B2 오차 29%는 배치 차이 때문 : B2 셀 77%가 학습 범위보다 짧은 수명 → 평균 +29% 길게 예측
  - B2 안에 충전시간으로 갈리는 두 그룹 존재 (MAPE 32.8% vs 16.7%). B2는 원논문 테스트 배치가 아니라 Target 직접 비교에 한계
  - B3는 12.6%로 원논문에 근접. 단 수명 1,100 이상 장수명 셀은 과소 예측

## 오류 분석
- 모델이 가장 크게 틀린 셀의 공통점 : 오차 상위 12개 중 11개가 B2, 그중 10개가 충전시간 10.17분 그룹(단수명).
  이 그룹 30셀은 전부 실제보다 길게 예측됨(+9.8 ~ +65.7%)
- 원인 가설 :
  - B2 수명이 학습 범위(534~1,074) 밖 → 외삽
  - 같은 ΔQ에서도 B2 셀이 더 일찍 수명 종료 → B1 규칙이 B2에서 어긋남 (ΔQ가 학습 범위 안인 B2 셀 MAPE 34.9%로 범위 밖 21.6%보다 오히려 큼)
- 개선 방향 :
  - ΔQ가 학습 범위(dQ_log_var -4.18 ~ -3.35) 밖이면 경고 → 외삽 셀 구분 (B3 범위 밖 MAPE 16.4% vs 안 9.1%)
  - 범위 경고로 못 잡는 관계 변화(B2형)는 새 배치 셀 몇 개의 실제 수명으로 재보정
    (B2 단수명 그룹 30셀이 전부 +9.8 ~ +65.7%로 같은 방향 편향 → 보정 여지 있음)


## 추가 실험 — Batch 2 소량 재보정 (`python src/improve_b2.py`)
개선 방향(재보정) 검증. 메인 성능표와 별개이며, '새 배치 셀 일부의 실제 수명을 안다'는 다른 시나리오라 원논문 Target과 직접 비교 불가
- 근거 : log 수명–dQ_log_var 기울기는 배치 간 거의 같고(B1 -0.30 / B2 -0.33 / B3 -0.31) B2 절편만 낮음 → 평행 이동이라 오프셋만 보정
- 방법 : B2 셀 k개의 실제 수명으로 log 오프셋 추정 → 나머지 B2 셀로 평가, 보정 셀을 무작위로 바꿔 500회 반복

| 실험 | B2 MAPE (%) |
|---|---|
| 기준 (B1 학습, 최종 모델) | 29.08 |
| B1+B3 학습 | 28.39 |
| 재보정 k=1 | 14.89 ± 6.95 |
| 재보정 k=3 | 12.26 ± 3.26 |
| 재보정 k=5 | 11.47 ± 2.01 |
| 재보정 k=10 | 11.05 ± 1.42 |

- 셀 5개로 29% → 11.5%. 단 10.04분 그룹은 거의 개선되지 않음(16.7 → 15.4%) → B2 안 그룹 차이 재확인
- B1+B3 학습은 효과 미미 : B3에도 B2 같은 단수명 셀이 없어(B3 최단 541) 학습 범위가 B2 쪽으로 넓어지지 않음
- 실제 수명을 얻으려면 표본 셀을 EOL까지 시험해야 함 (B2 기준 400~500 사이클)


## ESS 도메인 해석
- 활용 : 교체 시점 조기 계획 — 운전 초기 100 사이클 시점에 셀 수명을 추정해 교체 예산·일정을 미리 수립 (교체 비용 = ESS CAPEX 30~40%, 과제 자료 기준).
  단 학습 조건과 가까운 셀에서 오차 약 9~13%(B1 Valid · B3), 조건이 다르면 29%(B2)
- 한계 & 필요 사항 : 실험실과 실운영의 차이 — 데이터는 30°C 항온 챔버에서 4C 완전방전을 반복한 셀.
  실제 BESS는 부분 충방전·저율 방전·온도 변동이 있어 같은 방식의 ΔQ(완전방전 곡선)를 얻기 어려움
  → 주기적인 기준 진단 사이클(완전 충방전) 운영 또는 실운영 데이터로 재학습 필요
